# AdmitEase AI — University Admissions Assistant

**A Context Engineering & Prompt Engineering Project**

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Visit%20Website-gold)](https://westbridge-uni.netlify.app/)

## Project Overview

AdmitEase AI is a university admissions enquiry assistant prototype developed for Westbridge University, a fictional private university in Lagos, Nigeria.

The project explores how context engineering and prompt engineering can improve the accuracy, consistency and usefulness of AI assistant responses.

It combines structured university information, carefully designed instructions, prompt experimentation and response evaluation in an admissions support scenario.

## Project Objectives

- Demonstrate practical context engineering and prompt engineering.
- Build a structured knowledge base for a university admissions assistant.
- Compare different approaches to providing context to an AI assistant.
- Evaluate response accuracy and consistency.
- Develop a simple website interface for the admissions assistant.

## Key Features

- University information and programme enquiries.
- Admission requirements guidance.
- Application deadlines and document information.
- Application fee enquiries.
- Responses designed to avoid unsupported information.
- Floating chatbot interface on a university website.

## Context Engineering Experiments

The project involved three experimental runs using Claude:

| Run | Approach |
|---|---|
| Run 1 | Baseline prompt |
| Run 2 | Improved prompt with detailed information and instructions |
| Run 3 | Reusable context using a Claude Project and structured knowledge-base documents |

The experiments were compared to understand how different context strategies influenced assistant responses.

A context reduction exercise was also conducted to examine how removing relevant knowledge affected the assistant's ability to answer questions accurately.

## Evaluation

The assistant was tested using a set of 10 admissions-related questions.

The evaluation examined:
- Factual accuracy.
- Instruction following.
- Consistency.
- Handling of missing information.
- Avoidance of unsupported claims.

The findings informed improvements to the prompts and reusable context.

## Website Prototype

A simple university website was developed with a floating AdmitEase AI chat interface.

Westbridge University is fictional and is used solely for this educational project.

The website is a demonstration prototype. It does not accept applications, process payments, access student records or provide real admission decisions.
